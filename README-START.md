# 🚀 Empathy — старт с Claude Code

Эта папка — твоё рабочее пространство. Здесь ИИ хранит контекст о твоей роли и о том, как ему с тобой работать. Онбординг встроен — не нужно ничего ставить отдельно.

~20-30 минут на всё.

---

## Что понадобится

- Windows или macOS
- Терминал
- Личная подписка **Claude Pro или Claude Max** (не общий API-ключ компании — тарификация должна быть прозрачно твоя)

---

## Шаг 1. Установить Node.js (если ещё нет)

Проверь:
```
node --version
```
Если не установлен — скачай LTS-версию с [nodejs.org](https://nodejs.org) и поставь как обычную программу.

## Шаг 2. Установить Claude Code

```
npm install -g @anthropic-ai/claude-code
```
Проверь:
```
claude --version
```

## Шаг 3. Войти под своей подпиской

```
claude
```
При первом запуске Claude Code попросит авторизоваться в браузере — войди под своим аккаунтом Claude Pro/Max (не под чужим и не через общий API-ключ).

## Шаг 4. Открыть эту папку

Скачай/склонируй этот репозиторий, затем в терминале:
```
cd путь/до/этой/папки
claude
```
Claude прочитает `CLAUDE.md` и увидит, что онбординг ещё не пройден.

## Шаг 5. Пройти онбординг

Внутри Claude Code:
```
/empathy-onboarding
```
Скилл спросит про роль и задачи (Фаза A), затем — есть ли у тебя отчёт M0-аудита, Talent Q, и результат теста [empathy-behavior-profile.pages.dev](https://empathy-behavior-profile.pages.dev) (Фаза B, ~16 минут, пройди заранее если не проходил). По итогу заполнит `COMPANY.md` и `AGENT-PERSONALITY.md`.

## Что уже в папке

```
empathy-workspace/
├── README-START.md          ← ты здесь
├── CLAUDE.md                 ← инструкция для Claude, что читать при старте
├── COMPANY.md                 ← заполнится на онбординге
├── AGENT-PERSONALITY.md      ← заполнится на онбординге
├── .claude/
│   ├── settings.json          ← permissions
│   └── skills/
│       ├── empathy-onboarding/    ← скилл уже здесь, ничего ставить не нужно
│       ├── context-engineering/   ← M1 (недели 3-5) — что грузить в контекст, что нет
│       ├── daily-log/             ← M1 (недели 3-5) — ежедневный чек-ин, баллы в AI Champion
│       ├── atomize/               ← M1 (недели 3-5) — извлечение атомарных идей в заметки
│       └── reflect/               ← M1 (недели 3-5) — еженедельное ретро, черновик Mini-Demo
└── notes/                     ← сюда пишут /daily-log и /reflect по дням/неделям
```

---

## Позже, по ходу программы

Когда откроется новый модуль и новый скилл (M2, M3) — не проходи онбординг заново. Просто скажи Claude: «у меня появился `/имя-скилла`, обнови мой AGENT-PERSONALITY.md» — он сам найдёт нужный пункт в блоке «🔒 Роадмап-апгрейды» и обновит правило.

## Если что-то не так

- `claude` не найден → `npm install -g @anthropic-ai/claude-code` заново
- Просит войти заново → `claude login`
- Вопросы — пиши Кристине или Сержу
