# /atomize — Извлечение атомарных идей

## Workflow

1. **Спроси** что атомизировать (текст, путь к файлу, или вставленный параграф). Если пользователь уже дал контент — пропусти этот шаг.

2. **Прочитай** контент.

3. **Извлеки атомарные идеи** — каждая получает свою заметку:
   - 1 концепт на заметку
   - 2-5 предложений, переписанных СВОИМИ СЛОВАМИ пользователя (не копипаст из источника)
   - Теги на основе содержания

4. Для каждой идеи **поищи в папке atomic/** существующие заметки с потенциальными связями.

5. **Создай файлы** в `atomic/` с форматом: `YYYY-MM-DD_NNN.md` используя этот шаблон:

```markdown
---
id: YYYY-MM-DD_NNN
title: "[Описательный заголовок]"
date: YYYY-MM-DD
source: "[источник контента]"
tags: []
---

# [Заголовок]

[2-5 предложений, выражающих ОДНУ идею своими словами.]

## Connections

- [[related-note-id]] — [Почему это связано]

## Source Context

[Краткий контекст откуда это пришло]

---
*Created via /atomize*
```

6. Используй `[[wikilinks]]` для связей между заметками, с кратким объяснением каждой связи.

7. Выведи summary: **"X notes created, Y connections found to existing notes"**

## Правила

- Одна идея = одна заметка. Если нужно больше 5 предложений — разбей на две заметки.
- Всегда объясняй ПОЧЕМУ существует связь.
- Своими словами, не пересказ AI — это понимание пользователя.
- Если в atomic/ уже есть заметки — обязательно ищи связи с ними.
- Нумерация: если за день уже есть заметки, продолжай нумерацию (001, 002, 003...).
