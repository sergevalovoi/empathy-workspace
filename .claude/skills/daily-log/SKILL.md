# /daily-log — Empathy AI-эволюция

Это НЕ дневник курса ради дневника — это трекер прогресса по **твоему конкретному процессу**, который ты автоматизируешь по программе (M0-M3, см. `AGENT-PERSONALITY.md` / роадмап). Баллы отсюда идут в общий счёт, который на Demo Day (неделя 11) определяет 🏆 AI Champion — участника с максимальным счётом.

## Перед стартом

Прочитай (если есть): `COMPANY.md`, `AGENT-PERSONALITY.md`, `process-tracker.md`, `ai-champion-scoreboard.md`.

## Шаг 0 — Первый запуск (если `process-tracker.md` не существует)

Спроси один раз:
1. Какой процесс ты автоматизируешь прямо сейчас (из топ-3 матрицы M0)?
2. Сколько времени сейчас уходит на него — baseline (часов/неделю или минут/задачу — как удобнее считать)?
3. Какой сейчас модуль/неделя программы?

Создай `process-tracker.md`:
```markdown
# Мой процесс — трекер

**Процесс:** [ответ]
**Baseline:** [ответ] (зафиксирован [дата])
**Текущий модуль:** [ответ]
```

Дальнейшие daily-log читают этот файл — не переспрашивай, что за процесс, каждый раз.

## Шаг 1 — Мини-интервью (3-5 минут, разговорно, не форма)

1. **Что делал сегодня по процессу [название из process-tracker.md]?** — свободный текст
2. **Есть измеримая подвижка сегодня?** (не обязательно каждый день — если да, попроси цифру: сколько времени/шагов сэкономлено именно сегодня; если нет — "пока нет, работал над этим")
3. **Что мешало?**
4. **План на завтра** — 1-2 пункта по процессу
5. **Энергия:** 🔋 Высокая / ⚡ Средняя / 🪫 Низкая (через AskUserQuestion)

## Шаг 2 — Файл лога

Создай `notes/daily-log-YYYY-MM-DD.md`:
```markdown
# Daily Log — YYYY-MM-DD

## Процесс
[название из process-tracker.md]

## Что делал
[ответ]

## Измеренная дельта сегодня
[цифра или "—"]

## Блокеры
[ответ, или "—"]

## Завтра
[ответ]

## Энергия
[ответ]

---
*Логировано через /daily-log*
```

## Шаг 3 — Обновить `ai-champion-scoreboard.md`

Если файла нет — создай с разделами Дашборд / Стрик / Лог баллов / Ачивки.

**Начисление:**
- +2 балла — сам факт лога (регулярность)
- +5 баллов бонус — если сегодня была измеренная дельта (цифра, не "пока нет")

**Стрик:** подряд идущие рабочие дни (Пн-Сб). Воскресенье не считается и не ломает стрик.

**Ачивки (разблокируй при первом попадании условия):**

| Ачивка | Условие | Баллы |
|---|---|---|
| 🎯 Старт | Первый daily-log | +10 |
| 📝 В форме | 3+ daily-log | +20 |
| 📊 Первое измерение | Первая зафиксированная реальная дельта (не "пока нет") | +15 |
| 🔥 Неделя в потоке | 7-дневный стрик | +40 |
| 🏁 Готов к защите | Стрик без пропусков до конца текущего модуля (см. `process-tracker.md`) | +30 |

Итоговый счёт в `ai-champion-scoreboard.md` — это тот же счёт, который суммируется на Demo Day. Не изобретай отдельную систему уровней/XP — здесь одна валюта: баллы AI Champion.

## Шаг 4 — Короткий отчёт

Скажи, сколько баллов начислено сегодня и текущий стрик. Если разблокировалась ачивка — назови. Если энергия низкая — не дави, просто отметь.

## Edge cases

- **Уже логировал сегодня:** спроси, обновить или пропустить
- **Воскресенье:** лог не ожидается, стрик не страдает
- **Пропущенный будний день:** констатируй сброс стрика без нотаций, не изобретай штрафные баллы
- **Смена процесса** (участник начал автоматизировать что-то другое): предложи обновить `process-tracker.md`, старый baseline не удаляй — допиши историю ниже
